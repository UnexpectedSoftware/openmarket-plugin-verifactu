# test/vectors

Official AEAT hash examples from *Detalle de las especificaciones técnicas para la generación de la huella o hash de los registros* v0.1.2, §6.1–§6.3 (first alta, chained alta, anulación). `aeat-huella.json` holds the input fields, the canonical string, and the expected SHA-256. `test/hash.test.js` checks them.
